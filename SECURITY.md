# Security Policy

## Supported Versions
Aktuell wird nur die Version 0.x (MVP) entwickelt. Es gibt noch keinen offiziellen Support.

## Reporting a Vulnerability
Bitte melde Sicherheitslücken direkt per E-Mail an den Administrator oder erstelle ein vertrauliches GitHub-Issue, falls konfiguriert.
Da VereinOrder im lokalen Netzwerk betrieben wird, ist eine angemessene Absicherung des Netzwerks (WLAN) die erste Verteidigungslinie.
